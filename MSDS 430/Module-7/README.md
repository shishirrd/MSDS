# MSDS 430 — Module 7: Dictionaries, JSON, and Intro Text Analytics

## What it does
Works with hotel guest review data (Sandpiper Inn, Seattle) stored in JSON format. Parses
the JSON into Python dictionaries, extracts the review list, and applies string methods,
regular expressions, and the `Counter` module to analyze review text — an introduction to
text analytics and NLP fundamentals.

## Files
- `Deshpande_Module_7_Python_Assignment.ipynb`

## Data note
Ran against a JSON file of hotel reviews (`sandpiper_reviews.json`) — not included
(professor-provided dataset).

## Techniques/libraries used
- `json` module (parsing dictionaries)
- Regular expressions (`re`)
- `collections.Counter`
- TextBlob (introductory sentiment/text analysis)
