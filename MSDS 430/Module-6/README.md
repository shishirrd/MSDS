# MSDS 430 — Module 6: Data Visualization + EDA Continuation

## What it does
Continues the Module 5 state-rankings analysis with visualization: Seaborn pairplots to
inspect field relationships, a correlation matrix, derived/binned columns (`cut`/`qcut`),
groupby aggregations, and Seaborn/Plotly charting to test the population-growth,
land-area, and population-density hypotheses from Module 5.

Also continues the term-long EDA project (Austin spending dataset — see Module 4) at its
next milestone.
