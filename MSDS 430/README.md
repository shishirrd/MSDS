# MSDS 430 — Python Foundations for Data Science

Northwestern MSDS coursework covering Python fundamentals through applied exploratory data
analysis (EDA). Organized by module below.

| Module | Topic |
|---|---|
| [Module 1](./Module-1) | Python fundamentals (print, arithmetic) |
| [Module 2](./Module-2) | Booleans and conditional logic |
| [Module 3](./Module-3) | Loops, functions, exceptions |
| [Module 4](./Module-4) | File I/O (txt/csv/xlsx/json) + EDA project kickoff |
| [Module 5](./Module-5) | Data cleaning, prep, and merging (pandas) |
| [Module 6](./Module-6) | Data visualization (Seaborn/Plotly) + EDA continuation |
| [Module 7](./Module-7) | Dictionaries, JSON, intro text analytics |
| [Module 8](./Module-8) | EDA Phase 2 + assignment continuation |
| [Module 9](./Module-9) | Assignment continuation |
| [Module 10](./Module-10) | EDA project final report |

## Term-long EDA project
Modules 4, 6, 8, and 10 form a single continuous exploratory data analysis project on the
City of Austin's public financial "eCheckbook" dataset (municipal expenditure transactions),
progressing from proposal through final report. See [Module 4](./Module-4) for the project
rationale and dataset link.

## Note on large notebooks
A few notebooks in this course originally contained large embedded cell outputs (images,
dataframe displays) reaching tens of megabytes. Outputs were cleared for this portfolio —
code and markdown content are fully preserved; only rendered output was stripped.
