# MSDS 430 — Module 5: Data Cleaning, Prep, and Merging (pandas)

## What it does
Cleans and merges four datasets (U.S. News state rankings across 8 categories, state land
area, state population 2020-2024, and state budget data 1991-2024) to test hypotheses about
relationships between population growth, land area, population density, and category scores
(Economy, Natural Environment, Crime, etc.). Covers dataframe inspection, outlier checks via
boxplots, null handling, column/row selection, and merging into one clean analysis-ready
dataframe.
