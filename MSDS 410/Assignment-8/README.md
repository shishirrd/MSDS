# MSDS 410 — Assignment 8: Dichotomous Data (Wine Quality)

## What it does
Extends logistic regression modeling to a wine quality dataset, predicting a dichotomous
(binary) outcome from wine chemical properties. Covers summary statistics, model fitting,
and performance evaluation using ROC analysis.

## Techniques/libraries used
- R: `readxl`, `ggplot2`, `dplyr`, `knitr`, `gridExtra`, `moments`, `car`, `pROC`
- Logistic regression, ROC curve / AUC performance evaluation

## Data note
Ran against a wine quality dataset (`wine.csv`/`wine.xlsx`, with accompanying data
dictionary) — not included (course-provided dataset).
