# MSDS 410 — Regression Analysis

Northwestern MSDS coursework on regression modeling — progressing from simple linear
regression through multiple regression, variable selection, and generalized linear models
(logistic, Poisson, ZIP) — applied across four real-world datasets (Ames Housing, US States
demographics, Nutrition Study, ICU, Wine Quality, Stress).

| Assignment | Topic | Dataset |
|---|---|---|
| [Assignment 1](./Assignment-1) | Exploratory data analysis | Ames Housing |
| [Assignment 2](./Assignment-2) | Simple linear regression | US States demographics |
| [Assignment 3](./Assignment-3) | Multiple regression + nested F-test | Ames Housing |
| [Assignment 4](./Assignment-4) | Model building and diagnostics | Ames Housing |
| [Assignment 5](./Assignment-5) | ANOVA and categorical predictors | Nutrition Study |
| [Assignment 6](./Assignment-6) | Variable selection and model validation | Ames Housing |
| [Assignment 7](./Assignment-7) | Logistic regression basics | ICU data |
| [Assignment 8](./Assignment-8) | Dichotomous data (logistic regression + ROC) | Wine Quality |
| [Assignment 9](./Assignment-9) | Poisson and Zero-Inflated Poisson regression | Stress data |

## Ames Housing arc
Assignments 1, 3, 4, and 6 form a continuous model-building arc on the same Ames Housing
dataset — from initial EDA and transformation through multiple regression, model
comparison, and final variable-selected/validated model.
