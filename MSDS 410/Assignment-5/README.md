# MSDS 410 — Assignment 5: ANOVA and Categorical Predictors (Nutrition Study)

## What it does
Analyzes the relationship between dietary/lifestyle factors and Cholesterol levels using
the Nutrition Study dataset. Computes descriptive statistics of Cholesterol grouped by
PriorSmoke status, runs one-way ANOVA to test for mean differences between smoking-history
groups, and extends into regression modeling with categorical predictors.

## Techniques/libraries used
- R: `tidyverse`, `moments`, `dplyr`, `knitr`
- Descriptive statistics by group, one-way ANOVA
- Regression with categorical/factor predictors

## Data note
Ran against the Nutrition Study dataset (`NutritionStudy.csv`) — not included (small
course-provided dataset).
